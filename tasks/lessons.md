# Lessons

- 2026-10-23: When the user delegates choices and explicitly approves the proposed ideas, carry that authorization into implementation. Produce reviewable working UI; do not stop for another research summary or approval of the same direction.

- 2026-10-23: react-native-svg web forwards the native `accessible` prop to DOM. Hide decorative SVG with `aria-hidden` and verify browser console, not only TypeScript.

- 2026-10-23: Host permissions are determined by host-admin scope, even when the same device profile is assigned to a player team. Keep referee controls keyed to authority scope rather than assigned play role.

- 2026-10-23: When asked to follow a source game and its map workbench, implement and validate those behaviors against the source materials. A visual pass alone does not make the game playable; distinguish instructions for the players from mechanics the engine enforces.
- 2026-10-24: Treat the user's explicit correction that each player uses their own phone as the primary product requirement. A single-device referee flow is only a fallback/regression path; do not frame it as the intended finished game.
