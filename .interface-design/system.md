# Transit Field Kit

A city-wide game played from a marked-up transit map. Warm paper, navy ink, teal routes, signal yellow for the next action, and orange seeker identity. Map and decisions dominate; profile and runtime details stay secondary.

Use an 8-point spacing grid, paper surfaces, small 12-point card corners, and subtle offset depth. Display serif for game headings, sans for instructions, monospace for clocks/codes. Route stations are the signature for setup/navigation. Controls have 48-point minimum targets, visible labels and selected state, and tactile press feedback. Colour always accompanies text or shape.

Home: illustrated route map, one primary Start/Continue ticket, compact secondary play/settings. Lobby: two team spaces and a clear next step. Live game: compact role/clock strip, large map and bottom route navigation.
